# Полимеры — лаборатория устойчивости

Интерактивный учебный сайт о химической устойчивости пластмасс. Выберите полимер и фактор воздействия, чтобы увидеть схематичную SVG-анимацию и научное пояснение. Оценки в таблице ориентировочные: реальные свойства зависят от марки, состава и условий воздействия.

## Запуск

Требуется Node.js.

```sh
npm install
npm run dev
```

Для Windows PowerShell, если запуск `npm.ps1` запрещён политикой сценариев, используйте командные обёртки:

```powershell
npm.cmd install --no-package-lock
npm.cmd run dev
```

Откройте локальный адрес, показанный Vite в терминале.
